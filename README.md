# Новые истории — дашборд

Ритейл, Friends and Family и архив продаж собраны в одном файле.

1. Откройте [index.html](index.html) и нажмите **Download raw file** (значок скачивания).
2. Откройте скачанный файл в браузере. Переключатели вверху страницы открывают нужный раздел. Подключение к интернету не требуется.

В дашборде есть персональные результаты участников.
